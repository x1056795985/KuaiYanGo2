## 快速开始

### 环境要求

- Go >= 1.23
- MySQL >= 5.7
- Node.js >= 16（仅前端构建需要）

### 后端启动

```bash
# 1. 克隆仓库
git clone https://gitee.com/anyueyinluo/KuaiYanGo2.git
cd KuaiYanGo2

# 2. 设置 Go 模块代理（国内推荐）
go env -w GO111MODULE=on
go env -w GOPROXY=https://goproxy.cn,direct

# 3. 下载依赖
go mod tidy
go mod download

# 4. 修改 config.json 中的数据库连接信息
#    确保 MySQL 已启动且数据库已创建

# 5. 运行
go run main.go
```

启动后控制台会输出：

```
欢迎使用 飞鸟快验后台管理
当前版本: v.1.0.475
后台端口: :18888
管理员后台运行地址: http://127.0.0.1:18888/Admin
代理后台运行地址:   http://127.0.0.1:18888/Agentaa
web用户中心运行地址: http://127.0.0.1:18888/user/{AppId}
webSocket链接地址:  ws://127.0.0.1:18888/ws/{Token}
```

> 首次启动如数据库未配置，系统会在控制台提示输入数据库信息，也可通过管理后台 `/Admin` 页面初始化数据库。

### 前端构建（可选）

前端已内嵌打包在 `new/app/web/` 目录中，无需额外构建即可运行。如需二次开发前端：

```bash
# 管理员前端
git clone https://gitee.com/anyueyinluo/KuaiYanWeb.git
cd KuaiYanWeb
npm install
npm run dev    # 开发
npm run build  # 构建后将产物放入后端 web 目录
```

## 架构设计

系统采用经典的 MVC 分层架构，路由按角色隔离：

```
请求 → Router(middleware) → Controller → Logic → Service → Model/DB
```

### 路由分组

| 路由组 | 用途 | 鉴权中间件 |
|--------|------|-----------|
| `/Admin/*` | 管理员后台 API | IsTokenAdmin + IsToken飞鸟快验 |
| `/Agentaa/*` | 代理平台 API | IsTokenAgent + 鉴权代理权限 |
| `/WebApi/*` | 软件客户端调用 API | IsTokenWebApi |
| `/user/{AppId}/*` | Web 用户中心（前端页面） | - |
| `/userApi/*` | Web 用户中心 API | IsTokenWebUser |
| `/Api` | 用户安全 API（加密接口） | 入口解密 + 出口加密 + API 名称 MD5 加盐 |
| `/ws/{Token}` | WebSocket | Token 鉴权 |
| `/c/:shortUrl` | 短链接跳转 | - |
| `/webApi/payNotify/:order` | 支付回调 | - |

### 中间件

| 中间件 | 作用 |
|--------|------|
| `Cors` | 跨域放行 |
| `T统一恐慌恢复` | 全局 panic 恢复 |
| `鉴权TokenAdmin` | 管理员 Token 验证 |
| `鉴权TokenAgent` | 代理 Token 验证 |
| `鉴权TokenWebApi` | WebApi Token 验证 |
| `鉴权TokenWebUser` | Web 用户 Token 验证 |
| `入口解密` / `出口加密` | 用户 API 通讯加密 |
| `鉴权飞鸟快验` | 快验平台鉴权 |
| `检测数据库连接` | 数据库连接检测 |

### 数据库表（48 张）

涵盖：管理员、代理等级/库存/库存日志/授权、应用信息/WebUser 配置/推广配置、软件用户、用户类型/用户云配置/用户活跃、黑名单、卡号/卡类/卡类调价、签到系统（签到信息/签到日志/签到积分/签到任务日志/签到用户）、CPS 推广（推广信息/推广码/推广用户/推广支付订单/邀请关系/短链接）、定时任务/定时日志、链接令牌、各类日志（余额/卡号/登录/风控/用户消息/VIP 数量/代理操作/库存/提现/Key 操作）、公共变量/公共函数、在线统计、唯一编号日志、支付订单、任务池等。
